
# Vivado Reports

This folder contains the original Vivado reports for the parameterized synchronous FIFO.

- `fifo_utilization_synth.rpt` — Post-synthesis resource utilization.
- `fifo_utilization_impl.rpt` — Post-implementation resource utilization.
- `fifo_timing_summary.rpt` — Routed timing summary for the configured 100 MHz clock.

The timing report should be interpreted with the documented constraint limitations: input and output delays have not been specified.
